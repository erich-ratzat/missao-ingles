# Missão Inglês

MVP de inglês para crianças: missões curtas com história, personagens e reconhecimento de voz.

- Lucas: Esquadrão Estelar (construir e pilotar a nave)
- Henrique: A Grande Final (pênaltis)

Falas e vozes: `tools/roteiro.py` (requer `pip install edge-tts`). Rode `python tools/roteiro.py` para gravar o que faltar.
